# Context

## Glossary

- **Neovim configuration**: user-authored, version-controlled files that define editor behavior and can be edited from the development container.
- **Neovim state**: generated or downloaded editor artifacts, such as plugins, language tools, parsers, caches, and undo history. Neovim state is persistent but not version-controlled.
- **Tmux configuration**: user-authored, version-controlled files that define terminal multiplexer behavior and can be edited from the development container.
- **Tmux state**: plugin repositories downloaded automatically from declarations in the Tmux configuration. Tmux state is persistent but not version-controlled.
- **Supported container platforms**: 64-bit x86 development machines and Raspberry Pi systems running a 64-bit ARM operating system.
