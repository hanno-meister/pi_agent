# 0.2.0

## Highlights

- Add `openbrain`, an OpenCode profile for second-brain work with profile-local configuration, authentication, sessions, databases, and caches.
- Add Ponytail to the `code` profile, defaulting to `lite` mode, with commands to switch modes during a session.
- Expand the coding and second-brain skill collections, including LangChain, LangGraph, LangSmith, evaluation, pull-request, and retrospective workflows. The read-only LangChain specialist and its dedicated MCP servers remain opt-in.
- Add Tavily MCP support to `pibrain`, improve profile MCP configuration, and move second-brain linking into the `code` profile's skill system.
- Add visual Git blame mapping and update Neovim navigation and tmux configuration.
- Upgrade OpenCode to **1.19.0**, with the Docker image pinned to the same version.
- Update pinned agent tools, OpenCode plugins, and profile model mappings.
- Remove browser-backed voice dictation, the voice gateway, profile extension hooks, and voice-specific settings and shortcuts.

## Fixes and verification

- Resolve OpenBrain's pinned plugin through OpenCode instead of relying on untracked local `node_modules` files.
- Refresh the 25 LangChain/LangSmith skills from immutable MIT-licensed upstream revisions, retaining complete license text and provenance records.
- Narrow the generated Graphify skill's trigger to explicit Graphify requests and queries against an existing graph.
- Add offline fast checks to GitHub Actions, covering launcher behavior, Graphify skill generation, shell syntax, and no-voice integration regressions.

## Upgrading

- Rebuild the image with `docker compose up --build --detach` and restart agent sessions after updating profile configuration or plugins.
- When upgrading from a release with browser voice dictation, run `docker compose up --build --detach --remove-orphans` to remove the obsolete `voice-gateway` orphan from this Compose project while preserving named volumes. Do not add `--volumes`.
- Put provider credentials in the ignored `.env` file. The `pi` service receives that file's entries; host-exported credentials alone are not forwarded. Existing provider credentials remain unchanged.
- OpenBrain uses isolated authentication and state; credentials from another profile are not automatically shared. Its first plugin resolution requires network access.
- LangChain MCPs are disabled by default. LangSmith uses `LANGSMITH_API_KEY`, not the previously documented OAuth setup.
- Check model availability for your provider account before using the updated presets; alternate-provider mappings may need adjustment.
